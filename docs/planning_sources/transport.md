# TP.HCM transport overlay

Verified on 2026-11-24 by selecting QH 2030 on Guland at Gò Vấp. The map displayed the land-use raster and a separate transparent transport raster. Radar BDS registers only the latter under QH Giao thông, using the mainland TP.HCM expanded loading envelope and native zooms 10–17.

Source: https://guland.vn/soi-quy-hoach?lat=10.847771443414&lng=106.646657911

Tiles: `https://datacdn2.guland.vn/qh-hcm-100nam/giao_thong/{z}/{x}/{y}.png`. The GIS and Metro overlays previously used by this toggle are retired from the catalogue. Island coverage and individual route status have not been verified.
