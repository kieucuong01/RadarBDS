# Traffic P1-P3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build one deterministic 20-page traffic system that fixes homepage positioning, verifies discovery, strengthens truthful proof/internal links, and generates review-only distribution assets.

**Architecture:** `config/traffic_priority.py` is the single P1-P3 priority registry layered on top of the existing canonical page registries. Runtime presentation reads it through `services/traffic_priority.py`; the existing marketing audit, a bounded HTTP/GSC verifier, and a side-effect-free distribution generator consume the same entries. Existing SEO trust markup and the existing `/tin-tuc/du-lieu-radarbds` archive are extended, not replaced.

**Tech Stack:** Python 3.12, Flask/Jinja2, pytest, standard-library `csv`, `hashlib`, `json`, `urllib`, existing Radar BDS SEO registries and tracking contracts.

## Global Constraints

- The active registry contains exactly 20 unique canonical paths and exactly the 13 wards in `TDM_LIVE_WARDS`.
- The regular homepage H1 is `Săn deal nhà đất Bình Dương bằng dữ liệu`; `/bds-da-luu` keeps `BDS đã lưu`.
- Public proof comes only from an available live snapshot, a recorded published dataset, or factual method-only text; never synthesize counts, dates, conversion rates, legal claims, or freshness.
- GSC, analytics, network, authentication, and rate-limit gaps return `unknown`, never `pass`.
- Generated distribution assets always use `review_required`; no external post, email, webhook, browser, or outreach call is allowed.
- Do not expose phone numbers, email addresses, restricted original listing URLs, admin/auth URLs, credentials, or private fields.
- Do not change crawl order, normalization, deduplication, valuation, dataset versions, PostgreSQL schema, RBAC, Telegram, or social auto-post code.
- Preserve the current signal-first funnel and all existing AI-SEO/trust/redaction contracts.
- Use test-first red-green-refactor and commit each independently testable task.
